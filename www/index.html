Perceptual Science

Built with mathematical color precision

Unlike static theme switchers, walh-shell calculates balanced neutrals and announces palette metadata to child applications.

Oklab Derived Neutrals

color00 (surface) and color08 (dim) are dynamically derived in Oklab color space from each theme's true background and foreground, guaranteeing balanced panels and secondary text across any palette.

Instant Mode Announcement

Every theme exports WALH_MODE=dark|light and rxvt/ncurses standard COLORFGBG directly into the environment. CLI utilities and tools detect terminal mode instantly without slow escape query sequences.

Sub-Millisecond Execution

Zero Python, Node.js, or external binaries required at runtime. Themes are pre-compiled into lightweight POSIX/Zsh shell scripts emitting native OSC 4 / 10 / 11 sequences with truecolor precision.

Ecosystem Lifecycle Hooks

Define executable scripts in $WALH_SHELL_HOOKS to broadcast color changes to Neovim, tmux, Kitty, WezTerm, or Ghostty whenever a theme is switched.

Guides & Configuration

Extending walh-shell

Streamlined commands, plugin management with zload, hooks, and tmux compatibility.

Ultra-Fast Loading with zload

Pair with zload, the zero-friction Zsh plugin manager, for instant asynchronous startup and deferred completion compilation:

# In your ~/.zshrc zload casonadams/walh-shell # Or defer loading until first prompt: zload --defer casonadams/walh-shell

Unified Command Reference

Manage your terminal color schemes with intuitive, tab-completed subcommands:

walh tokyo-night # Apply a specific theme walh current # Inspect active theme and mode walh toggle # Switch between paired light/dark walh list --dark # List available dark themes walh random light # Apply a random light theme

Lifecycle Hooks

Configure $WALH_SHELL_HOOKS to broadcast colors to editors and terminal multiplexers:

export WALH_SHELL_HOOKS="$HOME/.config/walh/hooks" # Hook scripts receive: # $WALH_THEME (e.g. "tokyo-night") # $WALH_MODE (e.g. "dark") # $WALH_BG (e.g. "#1a1b26") # $WALH_FG (e.g. "#c0caf5")

tmux Truecolor & Passthrough

To allow dynamic OSC color sequences inside tmux, add these options to ~/.tmux.conf:

set -g allow-passthrough on set-option -g default-terminal "xterm-256color" set-option -sa terminal-overrides ",${TERM}:RGB"

Authoring Custom Themes

Add a simple TOML file in themes/ with paired [dark] and [light] palettes, then recompile:

# themes/my-theme.toml name = "my-theme" [dark] slug = "my-theme-dark" background = "#181825" foreground = "#cdd6f4" color01 = "#f38ba8" # red color02 = "#a6e3a1" # green color03 = "#f9e2af" # yellow color04 = "#89b4fa" # blue color05 = "#cba6f7" # magenta color06 = "#94e2d5" # cyan # Compile shell scripts & web previews: uv run generate_themes.py
